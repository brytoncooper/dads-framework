# Security policy

## Reporting a vulnerability

Keep vulnerability details private. When GitHub private vulnerability
reporting is enabled, open the repository's
[Security tab](https://github.com/brytoncooper/dads-framework/security)
and choose **Report a vulnerability**. If the button is missing, the
repository currently has no published private reporting channel. Keep
the details out of public issues and discussions.

Include the affected package and version, the conditions that reproduce the
problem, and the impact you believe it has. Remove credentials and personal
data from any logs you include.

You will receive an acknowledgement within a few days. Reporters are credited
unless they ask to remain anonymous. Package fixes are published in new
versions with release notes.

## Supported versions

Security fixes go to the current `main` branch and are released for the latest
published version of each affected package.
