# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub's vulnerability reporting for this
repository: open the **Security** tab and choose **Report a vulnerability**.
Include the affected package, a minimal reproduction, and the impact you
believe it has.

You will receive an acknowledgement within a few days. Reporters are credited
unless they ask to remain anonymous. Package fixes are published in new
versions with release notes.

## Supported versions

Security fixes go to the current `main` branch and are released for the latest
published version of each affected package.
