# Email delivery invariants

Rules about the `outbound_emails` outbox — the row that decides what is sent, when, and how often. The row is the source of truth and the retry engine; the jobs only decide when to look at it.

- INV-EMAILDELIVERY-1: An outbound email is claimed by at most one attempt — the claim is a single conditional UPDATE from `queued` to `sending` that increments `attempts`, so two workers racing the same row leave exactly one holding it — enforced by `src/delivery/lib/database/drizzle-outbound-email-store.ts#claimForSending`, `src/delivery/lib/database/drizzle-outbound-email-store.integration.test.ts`
- INV-EMAILDELIVERY-2: A row left in `sending` is never sent again automatically — the vendor may already have accepted the body, so a stale claim is failed with `STALE_CLAIM` and only an operator action re-queues it — enforced by `src/delivery/lib/database/drizzle-outbound-email-store.ts#failStaleClaims`, `src/delivery/lib/database/drizzle-outbound-email-store.integration.test.ts`, `src/delivery/lib/mutations/sweep-outbound-emails.mutation.ts`, `src/delivery/lib/mutations/sweep-outbound-emails.mutation.test.ts`
- INV-EMAILDELIVERY-3: The row is the only retry engine — a scheduled retry exists only as `status='queued'` plus `next_attempt_at`, computed by one pure function, so the in-process and BullMQ drivers retry identically — enforced by `src/delivery/lib/logic/next-attempt-at.ts`, `src/delivery/lib/logic/next-attempt-at.test.ts`, `src/delivery/lib/database/drizzle-outbound-email-store.ts#markRetryLater`, `src/delivery/lib/jobs/deliver-outbound-email.job.ts`, `src/delivery/lib/jobs/sweep-outbound-emails.job.ts`, `src/delivery/lib/jobs/email-jobs.test.ts`
- INV-EMAILDELIVERY-4: No email body, recipient address, subject or header value written by this kit reaches a log or the `last_error` column — a failure is summarized to its error class and message, and a thrown non-Error is named by its type rather than stringified — enforced by `src/delivery/lib/logic/summarize-delivery-error.ts`, `src/delivery/lib/logic/summarize-delivery-error.test.ts`, `src/delivery/lib/email-delivery.test.ts`, `src/delivery/lib/mutations/deliver-outbound-email.mutation.test.ts`
